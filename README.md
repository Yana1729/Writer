# 📂 Code Exporter

## 🇷🇺 Описание (Russian)
**Code Exporter** — это удобное Electron‑приложение для просмотра структуры проекта и экспорта выбранных файлов в единый документ (DOCX или HTML). Оно помогает быстро собрать исходный код в читаемом виде для отчётов, документации или презентаций.

---

### ✨ Возможности
- 📁 Отображение проекта в виде дерева папок и файлов
- ✅ Выбор как отдельных файлов, так и целых папок
- ❌ Возможность снять выбор с отдельных файлов внутри выбранной папки
- 🎨 Подсветка выбранных и исключённых элементов
- 💾 Экспорт в DOCX или HTML одним кликом
- ⚡ Удобный интерфейс в стиле IDE

---

### 🚀 Установка и запуск
- Клонировать проект:
``` bash
git clone https://github.com/username/code-exporter.git
cd code-exporter
```

- Установить зависимости:
```bash
npm install
```
- Запустить в режиме разработки:
```bash
npm start
```
- Собрать приложение:
```bash
npm run build
```

---

### 🖥️ Использование
- Нажмите «📁 Выбрать папку» и укажите корень проекта.
- Нажмите «🔍 Сканировать», чтобы построить дерево файлов.
- Выберите нужные файлы или папки.
- Клик по папке → выделяет все файлы внутри.
- Повторный клик по папке → снимает выбор.
- Клик по файлу → переключает выбор только этого файла.
- Можно снять выбор у отдельных файлов внутри выбранной папки.
- Нажмите «💾 Экспорт», выберите формат (DOCX или HTML) и путь сохранения.

## 🇬🇧 Description (English)
**Code Exporter** is a handy Electron application for browsing project structure and exporting selected files into a single document (DOCX or HTML). It helps you quickly compile source code into a readable format for reports, documentation, or presentations.

---

### ✨ Features
- 📁 Display project as a folder/file tree
- ✅ Select individual files or entire folders
- ❌ Ability to deselect specific files inside a selected folder
- 🎨 Highlighting of selected and excluded items
- 💾 Export to DOCX or HTML with one click
- ⚡ User‑friendly IDE‑style interface

---

###🚀 Installation & Run
- Clone the project:
```bash
git clone https://github.com/username/code-exporter.git
cd code-exporter
```
- Install dependencies:
```bash
npm install
```
- Run in development mode:
```bash
npm start
```
- Build the app:
```bash
npm run build
```

---

### 🖥️ Usage
- Click “📁 Pick Folder” and select your project root.
- Click “🔍 Scan” to build the file tree.
- Select the files or folders you want.
- Click a folder → selects all files inside.
- Click again → deselects the folder.
- Click a file → toggles only that file.
- You can deselect specific files inside a selected folder.
- Click “💾 Export”, choose format (DOCX or HTML) and save path.
